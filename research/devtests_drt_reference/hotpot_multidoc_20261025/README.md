# KnowMoreDiRT external multi-document source identity research, 2026-10-25

Source: Yang et al., [HotpotQA, EMNLP 2018](https://aclanthology.org/D18-1259/), original site https://hotpotqa.github.io/, **CC BY-SA 4.0**. Original untouched distractor development set is at `/data/tmp/kmd-hotpot-original-distractor-20261025.json` on Raspi (size 46,320,117 bytes, SHA256 `4e9ecb5c8d3b719f624d66b60f8d56bf227f03914f5f0753d6fa1b359d7104ea`). Downloaded once from publicly mirrored unchanged release `https://huggingface.co/datasets/RAGLAB/data/resolve/main/eval_datasets/HotPotQA/hotpot_dev_distractor_v1.json`, verified against the original release checksum in the authors' original HotpotQA `dataset_infos.json`. Raw original Wikipedia source and human answers are NOT silently rewritten or version-shifted.

`predict_unlabelled_retrieval.py` ranks every original question against its **provided 2–10 documents** using three lexical/source-aware baselines plus a fixed exact-title second-hop linkage. It accesses **no human gold** from source JSON. Its predictions are frozen with source hashes in `frozen_unlabelled_retrieval_20261025.json` (SHA256 `3b458f9dca38f0fd6a00896928d7df98c6269297c0da4a65fd4b22dfbd76cdf8`). `score_external_multidoc_gold.py` then looks up the original human supporting article/sentence IDs and records scores and paired uncertainty in `hotpot_external_multidoc_gold_results_20261025.json`. The first scoring attempt exited on an **overly strict assertion** that every question has at least six candidate articles; 60 original records legitimately have fewer, and the assertion alone was fixed **without changing the original frozen ranking file or any human labels**. The scoring results are recorded once after that assertion fix.

`audit_title_link_identity.py` is a post-score **forensic** source-offset and error audit, not a new independent evaluation or a tuned method. It reports 605 bridge recovery wins and 107 losses using explicit source article mentions, as well as comparison-class regressions, with exact source sentence indices and short original context. All expensive ranking work stays complete; scripts refuse to overwrite original result artifacts.

The existing `freeze_source_only_model_qa.py` separately froze **36 distinct multi-document question contexts** before any source-grounded Qwen answer call, by original question type × top-2 source rank disagreement (16 changed bridge, 8 unchanged bridge, 8 changed comparison, 4 unchanged comparison). Case IDs are SHA256 sorted independently of individual human answer gold. `run_source_only_qa_qwen_cpu.py` uses **identical prompts, model settings, source excerpt strategy and output budget** for direct reading of article pairs ranked by either full-text BM25 or fixed explicit-title second-hop source linkage. Model outputs are saved in a per-call checkpoint; `score_model_qa_external_gold.py` is only legal to invoke when **all 72 raw paired calls are present**, and then evaluates exact normalized gold answers, source quote exactness, source title validity and original human gold article/sentence coverage. **This is a source retrieval method comparison, NOT an automatically extracted DRS model comparison, and Qwen may know the original 2018 QA benchmark through pretraining.** Do not rerun a previously saved model call or change prompts based on label feedback.

For the currently verified full-corpus retrieval results and qualifications, read `../../../docs/kmd_hotpot_cross_document_research_2026-10-25.md`, then the earlier full [KMD discourse research](../../../docs/kmd_discourse_and_scientific_reasoning_2026-10-24.md) and [scientific discovery report](../../../docs/scientific_discovery_source_grounded_2026-10-24.md). The original three hard actor/identifier failures and previous model JSON failures remain unchanged.

## Source-linked diagnostic and externally frozen but unscored transfer

`audit_literal_link_limit.py` is a **post-gold descriptive** bridge limitation audit. Among 5,165 correctly recovered first gold articles, only 1,080 literally mention the exact title of the required other gold article; 4,085 do not, and 2,401 of those other gold sources are not the linked second article. It is not a DRS evaluation nor proof every absent literal title is an implicit coreference. The script and JSON source-linked diagnostic are preserved in this folder.

`predict_musique_untuned_transfer.py` and `frozen_untuned_musique_rankings_20261025.json` preserve the identical source-only retrieval method transferred (without retuning or expert annotation access) to original MuSiQue-Answerable dev: **2,417 records, 2–4 hops, 20 supplied source paragraphs each**, public author repository https://github.com/stonybrooknlp/musique under CC BY 4.0, original development source SHA256 `15fa63794d18a94ce12411aca6e2327e65b6e83b0b1490efab3f1962e48abf3b`. A separate tool safety check **denied the subsequent source-gold scoring action**; it was not repeated or moved to another executor. **Do not infer a transfer score or rank any methods from these unscored predictions.** The denial is not a failure of MuSiQue or proof against title link methods. The original source remains outside Git at `/data/tmp/kmd-musique-official-answerable-dev-20261025.jsonl`.

`clustered_source_uncertainty.py` is a separately recorded post-hoc uncertainty check of the SAME gold score, not a new hypothesis test. It resamples shared first-retrieved article titles, preserving source-cluster question dependence. It independently confirms the bridge improvement CI is not an artifact of many questions from one first source (5,820 clusters in 5,918 bridge questions); it does **not** correct dependencies through *second* sources or common Wikipedia facts.

## Completed source-answer model ablation and inference integrity

All **72** previously frozen Qwen inference requests completed under the original source-only two-article comparison contract. The original raw per-call JSONL `raw_source_only_qa_qwen_20261025.jsonl` is immutable. Human gold and source supporting paragraph/sentence IDs were read strictly later by `score_model_qa_external_gold.py`, yielding `source_grounded_model_qa_results_20261025.json`. The independently frozen 36 original question identifiers came from a SHA256 rank and source-pair change strata, without per-case gold selection or prompt tuning. Original Qwen model binary SHA256 `6a1a2eb6d15622bf3c96857206351ba97e1af16c30d7a74ee38970e434e9407e`; Raspi isolated CPU inference ran with nice 15, two threads, temperature zero, one call per method with identical source excerpt selection algorithm, unchanged gold and no repeated completed calls.

Despite linked retrieval furnishing both human evidence articles more often (**15/36 vs 12/36**), the source-answer model matched the human answer for **10/36 in each method**, with 3 gains, 3 losses and 30 ties. In the 12 identical-source negative control pairs, 11 answers and 9 citation strings were identical; citation variability cannot be attributed to article retrieval. Correct answers with missing gold documents may reflect shortcuts or latent model priors; original text quote string equality is not semantic entailment. One alias/title mistake conflated `Johnny English` with `Johnny English (film series)` and damaged a previously correct movie answer. Model output F1 and exact-match are reported separately; neither DRS nor scientific fact novelty was tested by this inference. The report above specifies the sample-selection/benchmark contamination limitations and case-level provenance.

`test_qwen_source_answer_integrity.py` checks the original dataset hash, frozen source/question conditions, per-method prompt/source-input hashes, checkpoint completeness, source quote validity flags and unchanged author answers. It invokes no LLM. This should be run only once all 72 original checkpoint lines and a completed scored JSON are present; the scorer and inference script both prevent silent replacement of completed original outcome files.
