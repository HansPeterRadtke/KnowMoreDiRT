# Semantic content of real neural DRS boxes — author gold from PMB 3.0

This is **a materially stricter external-ground-truth check of an actual published neural parser**, not a toy proof, handwritten oracle DRS, generated NLP model run or KMD deployment test. The independent source is the **human-corrected original Parallel Meaning Bank 3.0** test (898 utterances) and dev (885 utterances), pinned `RikVN/DRS_parsing@190838f9adea2af616eb76156d2e66c8565a6c6e`. The **published original model DRS outputs** from `RikVN/Neural_DRS@81bcb26dfcc08f0da999cc7beaa2952f8820860c` use `output/pmb-3.0.0/en/{test,dev}/bert_char_1enc/output1.txt`. Both original source datasets and parser outputs remain outside research Git and are asserted by SHA-256 in the code. PMB source annotations/DRS outputs are original copyright of the source authors; do not reproduce the whole dataset or weights without their terms. See the [official corpus repository](https://github.com/RikVN/DRS_parsing), [neural parser and precomputed outputs](https://github.com/RikVN/Neural_DRS), [PMB corpus research](https://research.rug.nl/en/publications/the-parallel-meaning-bank-a-framework-for-semantically-annotating/), and [formal DRT chapter](https://www.ims.uni-stuttgart.de/archiv/kamp/files/2011.kamp.van.genebith.reyle.discourse.representation.theory.handbook.pdf).

The specific generated `bert_char_1enc` architecture is described in the [2020 EMNLP BERT-plus-character DRS parsing paper](https://aclanthology.org/2020.emnlp-main.371/), not simply the older 2018 seq2seq baseline. Exactly one original raw sentence appears in both dev and test, so they are separate but not perfectly nonoverlapping textual sets.

The previous `pmb_external_20261024/` result found neural negation-operator *presence* 79/79 on test. `operator_scope_predicate_audit.py` instead **follows the original operator's actual subordinate DRS box** and separately compares annotated sense-bearing lexical concept inventory **within that source scope** to the **automatic neural model's** box. It recursively follows nested truth-functional operators and excludes outward presupposition links; arbitrary discourse variable IDs are ignored but lexical concept senses and multiplicity are retained. Every source split file is verified by predeclared literal SHA-256. `conditional_and_attribution_semantics.py` further requires **both the antecedent and consequent** of the original human implication to have the right semantic predicate content. `scope_named_referent_links.py` reconstructs real scoped lexical event to semantic role to named entity graph edges by original DRS Name annotations, without requiring exact arbitrary variable IDs. `source_scope_truth_consequence_summary.py` independently reads and checks the **preserved** result JSONs, and generates explicit Wilson intervals for original annotated exact-match rates. The models are **not rerun**, previous files are not overwritten, and no shared GPU/server is contacted.

New measured test results: exact original negation target *lemmas* 65/79 and exact lemma+sense 54/79, despite negation operator present in 79/79. Antecedent/consequent both exactly correct with lemmas 19/31; with lemmas+senses 16/31. Attributed statement scoped lemmas 8/18, exact senses 5/18. Within the subset of sentences with a gold proper named scoped negated event relation, model predicate–semantic-role–named-entity exactness 12/19 and with senses 10/19. Dev split has separate independent original gold/parse results; numbers are in original result JSONs. Concrete original semantic mismatches include model confusing Mary as Agent rather than Destination in a sentence about a rock that did not hit her, omitting Tom from the negative scope of a neither-Tom-nor-Mary sentence, and omitting tidy from a negated phrase meaning anything-but-tidy. The original sentence/box/named-referent records and source digests are saved for audit, not used to edit gold.

**Metric limitations:** lexical concept equality is necessary but insufficient for DRS truth equivalence: actual variable co-reference, quantification, temporal scope and embedding are more complicated; wrong sense need not invalidate every logical conclusion and an exact concept set can still have wrong roles. Named actor audit excludes most unnamed pronouns and cross-document identity. Original PMB model may share training-domain assumptions with annotations, and PMB utterances are not long real-life research documents or world-truth labels. Source-preserving parent/neighbor retrieval remains a distinct benchmark, already studied on original HotpotQA/ContractNLI data, and cannot be called worse/better on actual science solely from these PMB parser results. For longer scientific conclusions, see [`docs/kmd_drs_scope_content_validation_2026-10-25.md`](../../../docs/kmd_drs_scope_content_validation_2026-10-25.md).

`scope_failure_mechanisms.py` categorizes **nonexclusive** lexical extraction loss, lexical content placed outside the governing box, and spurious scoped predicates. Its unmodified original test negation group had fourteen lexical-content failures with at least one gold lemma absent from the generated sentence altogether, while a few conditional/consequence errors instead had the right lemma in the wrong subordinate scope. See original source-linked JSON and the long research report for explicit qualifications.
