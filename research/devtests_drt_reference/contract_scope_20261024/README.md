## Full external human evidence retrieval audit

`evidence_retrieval_benchmark.py` is a genuinely source-grounded baseline over *all* **123 original test contracts × 17 independently annotated hypotheses = 2,091 cases**. It uses lexical token-Jaccard span rank; no gold evidence spans enter ranking. Expanding each selected span by ±1 neighbor improves gold evidence recovery. Detailed result: `full_test_lexical_neighborhood_20261024.json`, source hash checked, no regeneration if result exists. The original legal document is supplied; this is an **oracle document** evidence-location baseline, not full-corpus document discovery, not model entailment and not DRS parsing. Human labels Entailment=968, Contradiction=220, NotMentioned=903. The last category deliberately has *no evidence spans*, so retrieval-based recall cannot establish correct abstention.

For top three exact spans **any human-gold evidence found**: Entailment **435/968**, Contradiction **59/220**. With ±1 neighbor context those become Entailment **590/968**, Contradiction **109/220**. Even at top ten expanded the method misses some evidence. This is legitimate external-negative evidence for sparse span retrieval, with an especially strong contradiction retrieval difficulty. Expansion increases input size and may introduce ambiguity; it is a recall-only measure, not a fair end-to-end accuracy comparison or proof that neighbors are always best.

## Frozen direct vs automatically extracted scoped-rule pilot

`freeze_contract_scope.py` froze original test examples for *one fixed NDA-20 hypothesis* (`Receiving Party may retain some Confidential Information even after the return or destruction of Confidential Information.`), in six distinct contracts with **2 Entailment, 2 Contradiction and 2 NotMentioned** human labels. Deterministic per-label SHA256 sorting was used **only at selection time**, and labels are never included in model prompts. Source text is automatically recovered from the corresponding contract's span set using the same predeclared top-three Jaccard scorer and ±1 neighbors, capped at 2,300 characters. Source document hashes, URL, span indices and exact selected text appear in `frozen_contract_source_scope_20261024.json`, SHA256 `0f7aa329b52413a21d0362a211856edf96297133f9c72001ad45ff14c2cd4d90`. Human gold evidence indices are withheld until after the recorded model outputs are complete.

`run_contract_scope_qwen.py` uses isolated local `Qwen2.5-1.5B-Instruct-Q4_K_M` on Raspi CPU (two threads, nice 15), with **identical actual source excerpts** in two paths. Direct asks for a structured verdict and source quote. Two-stage route automatically extracts one terse **source-only attributed permission/prohibition/condition/time/exception proposition**, validates its frame and exact copied quote, and separately judges the hypothesis from *only that model-derived structure*. Failed extraction must produce a clearly documented abstention, not guessed or perfectly hand-supplied semantics. This is a **DRS-inspired scope frame** and *not* the actual full KMD `chunk-drs-v5` grammar or operator semantics; outputs and costs are not matched by construction. Preserve raw outputs and all rejected frames; never retune prompts using test gold.

`score_contract_scope.py` runs **only after all six original model cases are checkpointed**. It reveals author human-gold verdict and exact expert source span indices strictly after inference, computes both verdict accuracies and how often the original evidence was present in supplied selected text, and preserves errors. A legally meaningful human-evidence label is **not proof of universal factual truth**. This does not test dream/fantasy worlds or independent causal science. The prior KMD actor-identifier failures, incomplete full-suite test and all original external gold remain unchanged.

## Completed six-real-contract model results (externally scored)

All six original source-aware Qwen calls and all six source-only typed-rule extractions finished on Raspi CPU under the original settings. The raw verbatim model results, model token usage, response finish reasons, exact source snapshots and hashes were checkpointed under `raw_model_comparison_20261024.jsonl` and **not rerun or overwritten**. Original ContractNLI human labels were read *after* inference by `score_contract_scope.py`, saved in `human_gold_contract_scope_results_20261024.json`. All three real test outcome classes were represented twice.

**Direct text-plus-provenance** matched **3 of 6** expert judgments: 1 correct contradiction, both NotMentioned correct, **both entailments incorrectly called NotMentioned**, and one contradiction case failed to produce a complete valid verdict within its output budget. It quoted an exact source substring on only **2 of 6** occasions. Cost **169.33 CPU seconds** total across six inputs.

**Source-only model-extracted scope rule → validated structure → second judgment** matched **2 of 6**: one correct contradiction, one correct NotMentioned, a NotMentioned case falsely called contradiction, two entailed rules called NotMentioned and one contradiction abstained after a failed extraction. Basic JSON/recognized-modality/valid-box-like-fields/**quote occurs verbatim in source** validation accepted **4/6** extracted rules; one returned invalid JSON, one included a non-verbatim quote. Their rejection produced safe NotMentioned defaults rather than invented facts. Cost **281.35 CPU seconds** total, greater than direct approach. This score is a small underpowered comparison with *unequal number of calls and output budgets*, not causal proof that DRT/DRS is worse. Full production KMD DRS remains untested on this source. Crucially, the validator's acceptance means **syntax and copied quote only**; it does not verify that the quoted passage semantically entails the extracted permission/obligation. Document ID 523's quoted two-year board-approval provision was associated with a purported `action: return` without textual support *inside that quote*; this is citation laundering that stronger semantic grounding needs to reject.

The expert-gold span audit identified an intact author-annotated source span in only **3/6** input excerpts. Therefore at least three cases were confounded by automated lexical source *retrieval*, and the model score cannot be interpreted as pure reasoning accuracy. The original contract-hypothesis expert distribution across **all 123 test documents** was `nda-20`: 33 Entailment, 30 Contradiction, 60 NotMentioned. Document attribution is essential even for the *identical* claim. This is real source-dependent legal scope, not **cross-document multi-hop identity**, fictional/dream facts or scientific novelty. Three source-stage failures cannot be repaired by perfect SAT logic alone; likewise high DRS operator F1 on PMB short sentences is not a guarantee of correct downstream decisions.
