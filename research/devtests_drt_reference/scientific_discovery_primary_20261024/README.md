# Scientific discovery: source-backed continuation (October 24, 2026)

This directory holds **actual scientific text-grounded retrieval, model evidence-assessment failures, and cross-publisher dated measurement analysis**, not a production DRS upgrade. Report and scientific bibliography: `../../../docs/scientific_discovery_source_grounded_2026-10-24.md`.

## External original data are not silently changed

SciFact: Wadden et al. (EMNLP 2020), https://aclanthology.org/2020.emnlp-main.609/, official repository https://github.com/allenai/scifact, local cloned repository commit `68b98a56d93e0f9da0d2aab4e6c3294699a0f72e`. Download original release from `https://scifact.s3-us-west-2.amazonaws.com/release/latest/data.tar.gz`; SHA-256 original compressed archive `11c621288d41ac144d29b13b0f8503b3820b7d6e8b1f6ff24dff335c196d76be`. Extract only `data/corpus.jsonl`, `data/claims_dev.jsonl`, `data/claims_train.jsonl` into `/data/tmp/kmd-scifact-release-20261024/`. SHA-256 values documented in the report and checked by scripts. SciFact claims+evidence CC BY 4.0, original S2ORC abstracts ODC-By 1.0, repo code Apache 2.0. The **original unmodified compressed dataset release** is retained as `original-scifact-release-20261024.tar.gz` with its exact SHA-256, along with the original upstream `SCIFACT_SOURCE_LICENSE.md`, for reproducibility if the public `latest` URL changes. The original extracted source corpus remains at the temp working path; output JSON includes claim IDs, document IDs, rank lists, labels and SHA-256 rather than needlessly duplicating raw abstracts.

Pure CPU retrieval: with the existing Python scientific environment use `OPENBLAS_NUM_THREADS=2 OMP_NUM_THREADS=2 /data/venvs/home-hans-dev/bin/python scifact_retrieval_ablation.py` **only on a clean alternate results destination**. The script refuses to overwrite the completed result. It uses predefined title TF-IDF, title+abstract TF-IDF and BM25 on all 5,183 original abstracts; exact source IDs, gold evidence group ID, top ranks and measurement results are in `scifact_fixed_retrieval_results_20261024.json`. It is **retrieval**, not science truth or DRS inference.

Separate CPU scientific evidence interpretation: `scifact_distinct_train_nli.py` used fixed 96 source pairs from **published train expert annotations**, source hashes, and an independent pretrained ONNX quantized model `cross-encoder/nli-MiniLM2-L6-H768`, revision `b95119ce93d3e065de6214e38cd4a97b0f2f2c6d`, `onnx/model_qint8_arm64.onnx` local 82,823,065 bytes. Local files only at `/data/tmp/kmd-scientific-nli-20261024`; no cloud model calls or inference server. `scifact_distinct_train_nli_frozen_cases_20261024.json` preserves sample IDs frozen before inference, `scifact_distinct_train_nli_results_20261024.json` contains every model inference, evaluated only after output generation. The result is **39/96 correct**, including fourteen *opposite polarity* assertions, and **is not proof of causal truth or field novelty**. Training annotations are disjoint from earlier *development* data, but the pre-trained model's historical exposure to all external scientific text cannot be fully excluded.

A different **development** NLI script `scifact_onnx_nli_baseline.py` generated predictions for 748 source-claim pairs but its result gathering failed with `KeyError: 'oracle_evidence_document'`. No model accuracy can be reconstructed from that run; no result JSON exists. **Do not repeat this consumed expensive experiment just to turn it into a success**. The failure belongs in negative evidence; separate future work could repair aggregation before a new truly independent test.

CERN and arXiv sources: `https://home.cern/opera-experiment-reports-anomaly-in-flight-time-of-neutrinos-from-cern-to-gran-sasso/`, `https://arxiv.org/abs/1212.1276`, `https://arxiv.org/abs/1208.2629`, immutable local HTML under `/data/tmp/kmd-scientific-realworld-sources-20261024`. **V1 wrong-actor scientific failure retained** in `real_neutrino_source_analysis_results_20261024.json`: generic arXiv category H1 was used as title, incorrectly identifying OPERA as ICARUS. **Corrected V2** in `real_neutrino_source_reasoning_corrected.py` reads `citation_title`, `citation_author`, `citation_date`, independently checks experiment identity and preserves V1 hash in new `real_neutrino_source_analysis_corrected_20261024.json`. Numeric extraction uses automatic pattern matching on original arXiv abstracts. Six regression checks in `test_primary_scientific_evidence.py` cover source integrity, historical as-of-time, actor identity, prediction arithmetic and the independently annotated SciFact error cases.

All scientific inferences are limited to provenance and explicit assumptions. Counterfactual date/world interventions are **manually selected controls**, not independent natural-language annotations or proof that the deployed KMD DRS models will parse arbitrary scopes. No original data, ground-truth labels, KMD production code or model-server configuration was changed. Research branch is separate from actively edited Infra and KMD master.
