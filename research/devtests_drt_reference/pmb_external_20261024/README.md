# Original published neural DRS vs gold scope (2026-10-24)

The gold test DRS clauses and exactly aligned natural language utterances were fetched **unchanged** from [RikVN/DRS_parsing](https://github.com/RikVN/DRS_parsing) Git commit `190838f9adea2af616eb76156d2e66c8565a6c6e`, source `data/pmb-3.0.0/gold/test.txt` and `data/pmb-3.0.0/gold/test.txt.raw`. The published neural model generated `output/pmb-3.0.0/en/test/bert_char_1enc/output1.txt` in [RikVN/Neural_DRS](https://github.com/RikVN/Neural_DRS) commit `81bcb26dfcc08f0da999cc7beaa2952f8820860c`. These original datasets and outputs remain **read-only** under `/data/tmp/kmd-pmb-eval-20261024` and `/data/tmp/kmd-pmb-reference-20261024` on Raspi. They are not republished here; see original authors and dataset reuse conditions. Exact source SHA-256 digests and result counts in generated JSON preserve snapshot identity.

Evaluation code is `pmb_semantic_scope_compare.py` and post-hoc followup `pmb_operator_ablation.py`. All inputs are **model-produced DRS representations**, not manually supplied perfect oracle DRS. The independent gold was fully corrected by human annotators as described in the PMB repository. A corpus record comprises one short sentence, not source-grounded research documents or cross-paper references. Each script refuses to overwrite its original result. The official original Counter run of one published parse was attempted on the local gold and returned normally; the authors' existing published `eval.txt` reports single-run clause F1 0.8897 and five-run mean 0.89204. We have not claimed a separately captured Counter aggregate from this turn because our local diagnostic invocation retained only a long detail-table tail.

The focused metric compares **presence of an operator in a source sentence**, not precise subordinate-box membership or the predicate negated. The real neural DRS recovered 79/79 gold sentences containing NEGATION with one false positive, while a simple English lexical negation rule got 73/79 and three false positives. The post-hoc analysis covers CONDITION, CONSEQUENCE, POSSIBILITY, ATTRIBUTION and YearOfCentury, with caveats: PMB's CONDITION includes quantifier restrictions and modal scopes not reliably signaled by the English word “if”; the lexical regex is intentionally far weaker than a provenance-aware retrieval plus semantic model. The YearOfCentury raw regex baseline actually surpassed the model on this small diagnostic. These results are genuine automatically extracted linguistic semantics but **not evidence of improved long-range KMD research accuracy, causal truth or novelty**.

Primary scientific papers: [PMB annotated corpus, Abzianidze et al. 2017](https://aclanthology.org/E17-2039/); [Neural DRS parsing, van Noord et al. 2018](https://aclanthology.org/Q18-1043/); [Neural Boxer at IWCS DRS shared task](https://aclanthology.org/W19-1204/); [Counter evaluation of scoped meaning representations](https://github.com/RikVN/DRS_parsing).
