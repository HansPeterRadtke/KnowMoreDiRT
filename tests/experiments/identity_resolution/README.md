This isolated experiment tests the DRS-side decision contract after vector retrieval. It does not modify production code. The resolver must choose an existing referent only when compatible evidence is strong and separated from the runner-up; otherwise it preserves ambiguity or creates a new referent. The tests cover exact identifiers, aliases, pronouns with relational context, same-role ambiguity, type conflicts, temporal conflicts, explicit new entities, and close-candidate margins.
