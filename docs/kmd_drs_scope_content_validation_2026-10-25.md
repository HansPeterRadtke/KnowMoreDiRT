# Automatic DRS scope-content accuracy: original human-corrected data and scientific-reasoning consequences

**KnowMoreDiRT research continuation, October 25, 2026.** This report answers the remaining original owner question: **Does an automatically parsed DRS actually preserve negation, conditional premises, quoted/attributed statements and actor roles, rather than simply generate a plausible semantic box?** It uses existing **real published model-generated DRSs** and independent human-corrected original linguistic gold—not hand-authored oracle tags or another synthetic logic puzzle. It must be interpreted together with [the complete cross-document KMD study](kmd_hotpot_cross_document_research_2026-10-25.md), [the KMD discourse/evidence report](kmd_discourse_and_scientific_reasoning_2026-10-24.md), and [the scientific-discovery report](scientific_discovery_source_grounded_2026-10-24.md). All historical negative fixtures (`hrq086`, `hrq087`, `hrq089`, and later context failures) remain intact.

## Independent published inputs and method

The original source sentences and linguistically human-corrected clausal Discourse Representation Structures (DRSs) were obtained **unchanged** from [`RikVN/DRS_parsing` Git commit `190838f9adea2af616eb76156d2e66c8565a6c6e`](https://github.com/RikVN/DRS_parsing/tree/190838f9adea2af616eb76156d2e66c8565a6c6e), Parallel Meaning Bank (PMB) **3.0**, test **898** sentences and development **885** sentences. The trained neural parser's **original previously published generated outputs**, rather than model re-runs or manually repaired annotations, were obtained from [`RikVN/Neural_DRS` Git commit `81bcb26dfcc08f0da999cc7beaa2952f8820860c`](https://github.com/RikVN/Neural_DRS/tree/81bcb26dfcc08f0da999cc7beaa2952f8820860c) at `output/pmb-3.0.0/en/{test,dev}/bert_char_1enc/output1.txt`. Its published `eval.txt` lists *overall* clause F1 of **0.8897 for that test output** and approximately **0.892 mean across five outputs**. High overall clause F1 should **not** be mistaken for near-perfect rule interpretation. PMB's methodology is described in [Abzianidze et al., *The Parallel Meaning Bank*](https://research.rug.nl/en/publications/the-parallel-meaning-bank-a-framework-for-semantically-annotating/); the precise **BERT-plus-character model family** in [van Noord, Toral and Bos, *Character-level Representations Improve DRS-based Semantic Parsing Even in the Age of BERT*, EMNLP 2020](https://aclanthology.org/2020.emnlp-main.371/), with earlier foundational neural DRS work in [van Noord et al., 2018](https://aclanthology.org/Q18-1043/).

The **original gold and published model output files remain read-only outside this repository** under `/data/tmp/kmd-pmb-eval-20261024` and `/data/tmp/kmd-pmb-reference-20261024` on Raspi. Every read has SHA-256 assertions for both original test and dev source sentences, gold and model output files. Research-owned derived scripts and small sampled source excerpts are under `research/devtests_drt_reference/pmb_external_20261025/`; no original gold, model output or KMD production code was changed.

The previous PMB experiment measured whether the generated DRS **contains the negation operator at all**: the parser detected all **79/79** gold-negated test sentences with **one false positive**. The new, materially stricter analysis asks **what semantic content that negation or conditional actually governs**. `operator_scope_predicate_audit.py` follows each original DRS box link from `NEGATION`, `CONDITION`, `CONSEQUENCE`, `POSSIBILITY`, or `ATTRIBUTION`; it follows nested truth-functional/modal boxes and intentionally excludes outward presupposition links. Then it compares the **original gold's sense-labeled predicates** inside that scope against the predicates the model itself put there. DRS box IDs and event variables are **alpha-normalized by comparing actual scoped lexical content**, not their arbitrary raw `x1`/`e2` labels. The primary comparison preserves lexical multiplicity and treats a mismatch in the word sense separately from a mismatch in the underlying lemma.

`conditional_and_attribution_semantics.py` also requires the model to represent *both* the antecedent and consequent of a human-annotated condition with the correct scoped predicates. This is a **necessary but not sufficient** prerequisite for a formally valid downstream scientific inference. `scope_named_referent_links.py` resolves original named participant referents via DRS `Name` annotations and compares scoped event-predicate → semantic-role → named-participant links to gold, independent of the neural parser's arbitrary variable IDs. It is restricted to sentences with a clear proper-name and in-scope event role: **it does not measure all pronouns, complex coreference, identity or full logical equivalence**. Finally, `source_scope_truth_consequence_summary.py` computes original-instance Wilson intervals; these are descriptive sampling uncertainty assuming independent examples, not model training or causal confidence.

## New measured results: operator present versus correct scope content

All figures below were computed on **the original published neural parser's output**, not perfect hand-authored DRSs. “Exact lemmas” requires the **multiset of lexical predicates in the targeted scope** to match gold; “exact senses” additionally requires gold lexical senses. Neither means the whole DRS is logically equivalent to gold, because roles, quantification and referent accessibility can still be wrong.

| Gold semantic requirement | PMB test | PMB development |
| --- | ---: | ---: |
| Detect any gold negation | **79/79** | **70/70** |
| Preserve exact negated **predicate lemmas** | **65/79** (82.3%) | **60/70** (85.7%) |
| Preserve exact negated lemmas **and senses** | **54/79** (68.4%) | **41/70** (58.6%) |
| Detect both antecedent and consequence boxes | **25/31** | **31/32** |
| Preserve both conditional branches' exact lemmas | **19/31** (61.3%) | **22/32** (68.8%) |
| Preserve both branches' exact lemmas **and senses** | **16/31** (51.6%) | **14/32** (43.8%) |
| Detect attribution/report scope | **16/18** | **26/27** |
| Preserve exact attributed predicate lemmas | **8/18** (44.4%) | **21/27** (77.8%) |
| Preserve attributed lemmas **and senses** | **5/18** (27.8%) | **16/27** (59.3%) |

For test negation-scope **exact lemma inventory**, 65/79 has descriptive Wilson 95% interval about **72.4–89.1%**; for complete gold conditional antecedent-plus-consequent sense content, 16/31 has interval **34.8–68.0%**. Test and development are from the same original dataset/annotation tradition and do not establish independent source domains. The attribution test sample is particularly small. Precise interval denominators, original source hashes and counterexamples are in `drs_semantic_necessary_conditions_summary_20261025.json` and `original_pmb_implication_attribution_scope_audit_20261025.json`.

**Meaning:** a parser can emit a perfectly recognizable `NEGATION` or `CONDITION` structure while misidentifying the proposition that has been negated or the premises and consequences of a purported rule. Using such a structure as an automatically certified fact or logical rule would promote a *semantic extraction error* into apparent logical certainty. The formal DRT semantics—see [Kamp, van Genabith and Reyle's primary chapter](https://www.ims.uni-stuttgart.de/archiv/kamp/files/2011.kamp.van.genebith.reyle.discourse.representation.theory.handbook.pdf) and the [Stanford Encyclopedia of Philosophy's DRT article](https://plato.stanford.edu/entries/discourse-representation-theory/)—explicitly interpret the *conditions inside* each negation or implication box. Their correctness is therefore indispensable; an operator's mere presence is not a valid proof.

## Real errors and identity/source implications

The original gold sentence about a room being **“anything but tidy”** correctly has *tidy* inside the negated box; the neural parser emits a negation box but **omits its `tidy` predicate**. A sentence where a person says they cannot pronounce another person's surname has the correct gold *pronounce* event in the negated scope; the model emits *be*. The real sentence **“I think he ate about 10 oysters”** has gold attributed *oyster* content, but the generated attribution box instead contains an unrelated *mosque* concept. This is a semantic content error, not an inference from other documents. Gold test PMB sentence offsets/indices 102, 177 and 51 respectively are stored along with the automatically generated erroneous clauses.

The deeper **named referent / agent role audit** also found serious participant errors even where the main lexical event was recognized. On the test split, among **19** gold negation sentences whose scoped event was linked to an explicit original named source entity, the model reproduced **the exact predicate–role–name combinations in 12/19** (63.2%, Wilson 95% about **41.0–80.9%**); requiring the original senses yielded **10/19**. By contrast the separate development split had **17/17** exact lemma-role-name matches for that narrow subset but **10/17** with senses: the performance fluctuates and is not a comprehensive identity score. Importantly, one model put **Mary as `Agent`** in a *negated hit* event in the sentence about Tom throwing a rock that did not hit Mary. The original human DRS puts Mary as the event's **`Destination`**; the rock was the implied subject of the failed hit. Another actual sentence about **neither Tom nor Mary going to the store** had *both* Tom and Mary as negated event participants in the gold, but only Mary in the model's negated scoped role links. A sentence saying **Chen is not Korean** lost the proper named *Chen* participant from the generated negated-event relation while retaining the source nationality location. These original DRS examples are at test indices 624, 735, 487.

These are **not tests of actual KMD production code** or a direct reproduction of original KMD `hrq086`, `hrq087`, `hrq089`. They are independently annotated real semantic data demonstrating **a plausible mechanism for KMD's existing unresolved actor/identifier failures**: a model can bind the correct predicate, a superficially compatible source sentence and even the correct named entities to the *wrong role* or *wrong scope*. A downstream SAT/SMT solver can validate deductions from the extracted proposition perfectly and still arrive at a false description of the original text if that extraction is wrong. The model has not thereby discovered a new fact, let alone falsified a physical hypothesis. Named proper-word/source-label matches and exact sentence copying are necessary source controls but not a semantic entailment certificate.


### Extraction errors are not all the same failure

A follow-on source-checked error taxonomy (`scope_failure_mechanisms.py`) separated missing lexical predicates, misplaced predicates and extra predicates without counting the categories as mutually exclusive. Of the **14/79 test negation sentences with incorrect lemma inventories**, **all fourteen omitted at least one gold negated lemma from the model's entire sentence representation**, and nine also contained at least one spurious lemma inside negation. This points primarily to **lexical-semantic extraction errors** in that test subgroup, rather than merely box placement; the separate **development** split included eight missing-gold-lemma cases and two with a gold lexical predicate present elsewhere but not inside the negated box. By contrast, the test gold CONDITION boxes had **six** examples where a needed gold lemma appeared somewhere in the generated DRS but **outside the correct governed scope**, and the CONSEQUENCE boxes had **seven** such cases. So valid model output can fail because the predicate was never extracted, because it was assigned the wrong scope, or because an event's participant role was wrong. The errors are separate and may overlap; simply increasing neighbor retrieval cannot fix all three. Source-scoped inference must reject a derived conclusion if a required predicate/actor premise is not grounded in its original clause.

This original dataset's **test and development partitions have only one identical source sentence in common** by exact text, but share annotation style, topic and neural model development; they should not be described as wholly independent source domains. The published model parsed both splits originally; no new inference-time model calls were made in this audit.

## Does DRS outperform provenance-aware neighboring retrieval?

The resulting answer is **conditionally positive only at the semantic representation layer, still unresolved end-to-end**. In the original 898-sentence test split, trained neural DRS clearly added some **implicit negation and source-operator information beyond crude word cues**, as measured earlier. But the stronger predicate and referent-role audit shows that operator detection is an overly optimistic proxy: when predicate *content* and participant *identity role* matter, a material minority of original outputs fails. There is **no matched-budget, independently gold-labeled production KMD experiment showing DRS outperforms the strongest provenance/source-title/neighbor-plus-source-link baseline on long real documents with correct dream, quote, tense and cross-file identity resolution**.

The larger independently annotated 7,405-question [cross-document HotpotQA benchmark](kmd_hotpot_cross_document_research_2026-10-25.md) did establish **a source-title link gain of 8.4 percentage points for recovering both supporting documents on bridge questions**, but a paired 36-question local Qwen downstream experiment yielded **10/36 exact answers either way**. PMB DRS was not applied to those Wikipedia documents, and Hotpot retrieval labels cannot be converted into fake gold DRSs. Conversely, this PMB parsing experiment uses relatively short original sentences; it has no dream, fictional law, historical supersession or multi-author scientific premise labels. **The two results answer different stages of the workflow and must not be merged into a fictional single end-to-end DRS score.**

Published examples of genuinely new automated biological or mathematical discovery through independent experiments/grounded evaluation (Adam, FunSearch and conditional scientific hypothesis tests) are documented in the existing scientific-discovery report. This new PMB audit establishes an important **necessary reliability requirement** for that owner's ambition: any accepted formal proposition should retain its original source plus a *checked* box-specific predicate, actor/target role and time/world scope, and the system must abstain when extraction confidence or original evidence fails. Exact URLs/line offsets, negative evidence and later real outcomes remain prerequisites for independent falsification and novelty adjudication. Full KMD production DRS versus provenance benchmark and genuinely novel scientific discoveries **remain unproven**.
